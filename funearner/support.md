# FunEarner — Support

_Last updated: 2 August 2026_

Need help with FunEarner? You're in the right place.

## Quick answers

**The app asks for Screen Time authorization — is that safe?**
Yes. FunEarner uses Apple's Family Controls framework, which is sandboxed. FunEarner never sees the raw list of apps your child used; it only receives the aggregated signals it needs to unlock rewards.

**Where is my data stored?**
- **Self mode**: everything stays on your device. No account, no login.
- **Family mode**: rules and reward history are synced between the parent's and the child's devices through **Apple iCloud (CloudKit)**. The data stays inside your own iCloud. The developer has no access to it and there is no separate server or account.

**How do I link a parent device with a child device (Family mode)?**
On the parent device, open FunEarner → Family mode → *Add a child*. The app generates a QR code and an invitation link. On the child's iPhone/iPad, scan the QR code (or open the link) and accept the iCloud share. Both devices are now linked. You can revoke the link at any time from the parent app.

**A shield/limit isn't triggering.**
Make sure Screen Time authorization is granted in **Settings → Screen Time** and that FunEarner is allowed. Restart the device if a rule was just added.

**How do I remove all data?**
Uninstalling the app erases all local data. In Family mode, also revoke the iCloud share from the parent device before uninstalling — this removes the shared record from both devices.

**Does Family mode work if the child doesn't have an Apple ID?**
No. Family mode relies on iCloud sharing, so both the parent and the child device need an Apple ID (a child Apple ID via Family Sharing is fine). Self mode works without any Apple ID.

**Does it cost anything?**
No. FunEarner is free and has no in-app purchases at the moment. Family mode uses your own iCloud storage (well within Apple's free tier for this kind of data).

## Contact

Send an email to [itunes@allamand.com](mailto:itunes@allamand.com) with:
- Your device model and iOS version
- Whether you use Self mode or Family mode
- A short description of the issue
- Screenshots if relevant

We usually reply within a few working days.
